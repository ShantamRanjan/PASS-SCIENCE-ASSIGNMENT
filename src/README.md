# NEXUS Source Architecture (`src/`)

This directory provides the consolidated source code references for the Unified Engineering Workbench:
1. **C++ Backend Engine**: Located in `backend/src/` and `backend/include/` (C++17 native solvers, REST API, geometry, performance, hardware, and ML kernels).
2. **Frontend Presentation**: Located in `frontend/pixel-perfect-replay-45857-main/src/` (React 18, TypeScript, Three.js 3D viewport, route components, and state hooks).
